# Red String

**Pitch**: 5 block detectives read the web; a red string means the sources disagree.

### What It Does
Press Replay or speak a premise into the mic. Five block detectives chatter aloud with newsroom banter in a 3D block town, quoting checkable facts on board cards. A red string snaps between disagreeing sources. (Hurricane Maria replay: 112 sources, 68 claims quoted, 1 red string on landfall date; gold primary record).

### How It Uses Parallel
- **Search**: Discovers reporting and primary records concurrently.
- **Extract**: Re-checks live pages to confirm corrections.
- **Task**: Runs the Editor's verdict and schema validation.
- **FindAll**: Resolves the people and entities involved.
- **Image Search**: Populates board cards with media.

### How It Was Built
Built in two hours by 5 autonomous agents collaborating across 3 vendors: Anthropic Claude Code, OpenAI Codex, and Google Antigravity.
