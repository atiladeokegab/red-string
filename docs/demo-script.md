# Red String: Hurricane Maria Demo (2–3 min)

5 block detectives read the web; a red string means the sources disagree.

Speak into the mic: detectives answer aloud in the Investigators' channel. We run on Replay—the demo fallback.

On a studded baseplate, five detectives read 112 sources and stack 68 checkable claims into towers.

A red string snaps between disagreeing towers. It didn't flag 64 vs 4,645, because those are the toll before and after the recount; it flagged the one place a source gives a different date for the same event: a NOAA page gives two different landfall dates; 15 sources including USGS say 20 Sep.

Click either tower to read literal quotes side by side. The primary record stands in gold, settling the true date.

The Sceptic threw out every false match: same fact at a different stage, different units, hedged estimates. Red String never guesses: it reports what the web actually said.
