# Red String: Hurricane Maria Demo (2–3 min)

### 30-Second Opening Hook
"5 block detectives read the web; a red string means the sources disagree. While other AI assumes the web agrees with itself, Red String reads conflicting sources, stacks facts into toy towers, and snaps a glowing red thread between contradictions."

### Demo
Speak into the mic: detectives chatter in the Investigators' channel across a block town. We run on Replay.

112 sources read, 68 claims stacked. A glowing red thread snaps on landfall date: a NOAA page gives two dates; 15 sources say 20 Sep.

Crew banter:
- Sceptic: *"Stop. 20 Sep 2017 versus 22 Sep 2017. Can't both be true."*
- Archivist: *"The primary record says 20 Sep 2017."*
- Editor: *"We run 20 Sep 2017 and flag the dispute."*

Case-file cards show literal quotes. The Sceptic ignored 64 vs 4,645 recount stages; it caught the real contradiction: same event, different dates.
